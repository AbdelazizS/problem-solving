## Repository Structure

```
arrays/          → array problems by number
strings/         → string problems
hashing/         → dedicated hashing problems
patterns/        → pattern reference notes
cheatsheets/     → quick reference guides
templates/       → reusable templates for new problems
progress.md      → overall stats and mastery tracking
```

Each problem folder contains:
- `Solution.java` — final accepted solution
- `notes.md` — learning journal (mistakes, takeaways, similar problems)
- `README.md` — quick summary (pattern, complexity, status)
